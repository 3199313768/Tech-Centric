# 庭院导引样式统一设计

## 目标

解决庭院导引入口、聊天面板、欢迎区、气泡、快捷 chip、输入条材质与圆角「打架」的问题，在不动插画资产与交互结构的前提下，用 SpiritGarden token 做轻量视觉统一。

## 决策摘要

| 项 | 决策 |
|----|------|
| 范围 | 全量表面（入口 + 面板 + 欢迎 + 气泡 + chip + 输入） |
| 主因 | 元素风格不统一（通用 `--color-*` / cyan 焦点 / 阴影语言混杂） |
| 幅度 | 轻量：以 CSS 为主，不换插画/精灵，不改交互与 DOM 结构 |
| 方案 | Token 对齐：统一材质、圆角阶梯、软阴影 |

## Token 与视觉阶梯

### 材质

- 表面：`var(--sg-paper)` / parchment 系半透明
- 边框：浅色 `rgba(238, 224, 210, 0.45)`；深色 `rgba(161, 212, 148, 0.14)`
- 文字：`var(--sg-ink)`；次级沿用绿灰 muted
- 强调：`var(--sg-green-deep)`；深色 `var(--sg-green-light)`
- 去掉导引区内 cyan 焦点环与混用的 `--color-ai-*` / `--color-card-*`（改写为 garden 等价）

### 圆角阶梯

| 元素 | 圆角 |
|------|------|
| 悬浮入口 | 圆形（保持） |
| 面板 | `24px` |
| 欢迎卡 / 助手气泡 / 输入条 | `16px` |
| 用户气泡 | `16px`（可保留一角略收，阴影降噪） |
| chip / badge | `9999px` |

### 阴影

统一软阴影（接近站点卡片：`0 16px 40px -20px rgba(74, 66, 56, 0.2)`），降低入口与用户气泡的「浮夸」多层阴影差异。

## 触达文件

- 主改：`src/app/globals.css`（`.sg-rag-*` 区块）
- 不改：`FloatingAssistant.tsx` / `ChatPanel.tsx` 结构（除非 class 名已存在的微调）
- 资产不变：`rag-guide-sprite.webp`、`rag-guide-welcome.webp`

## 分区落地

1. **入口**：边框/阴影改 garden；保留精灵与 hover 微抬  
2. **面板 + 页头**：底色与边框改 `--sg-*`；badge 为 parchment 描边绿字  
3. **欢迎区**：与面板同材质，减弱嵌套卡片对比  
4. **气泡**：助手 parchment 浅底；用户深绿，阴影降噪  
5. **chip**：描边弱芯片，hover 浅绿 tint  
6. **输入条**：焦点环改 `sg-green`，去掉 cyan  

## 验收标准

1. 浅色下入口打开后，面板/欢迎/chip/气泡/输入条一眼同族。  
2. 深色下边框可读，无 cyan 焦点。  
3. 欢迎插画与精灵资产、交互流程不变。  
4. 既有「打开庭院导引 / 欢迎插画」选择器仍可用。  

## 非目标

- 重排欢迎区/页头 DOM  
- 更换或重绘插画  
- 改 RAG 请求、联系流程、文案逻辑
