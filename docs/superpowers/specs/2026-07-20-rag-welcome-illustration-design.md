# RAG 公开助手欢迎插画设计

## 目标

为 RAG 公开助手首次打开时的欢迎区补充一张完整主视觉，解决当前只有小型星光图标、缺少视觉角色与识别度的问题，同时不挤占实际对话空间。

## 设计方案

- 新增一张“庭院 AI 导引精灵”水彩插画：友好的微型植物精灵守在发光书页与知识枝叶旁，表达检索、引导与知识连接。
- 图片不包含文字、品牌标识或具体聊天界面，避免与动态欢迎文案冲突。
- 色彩沿用 SpiritGarden 的自然绿、纸张米色与少量青蓝光，适配现有浅色和深色面板。
- 采用接近横向卡片的紧凑构图，主体清晰、边缘留白，适合窄聊天面板展示。

## 接入范围

- 将生成图片保存到 `public/spirit-garden/`。
- 仅在 `ChatPanel` 的空消息欢迎区展示插画。
- 用户发送第一条消息后，插画随现有欢迎区一起隐藏。
- 悬浮入口、聊天头部、消息气泡、RAG 请求与联系流程保持不变。

## 无障碍与性能

- 使用 `next/image` 和明确的响应式尺寸。
- 插画承担氛围作用，设置空 `alt` 并隐藏于辅助技术，欢迎标题与说明继续提供完整语义。
- 输出适合网页的压缩格式，控制体积，避免明显延迟聊天面板打开。

## 验证标准

1. RAG 助手首次打开时，欢迎文案上方展示完整插画。
2. 图片在聊天面板内不溢出，移动端与桌面端均保持合理比例。
3. 发送消息后欢迎区和插画正常隐藏，对话流程不受影响。
4. 浅色、深色主题下插画与容器边界协调。
5. `pnpm lint` 与 `pnpm typecheck` 通过。
